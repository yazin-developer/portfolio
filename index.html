Background & Philosophy

The Mindset of a Builder & Breaker

How an early fascination with game mechanics and physics simulations led directly to cybersecurity and systems engineering.

I didn't start my coding journey with standard web tutorials. I started by trying to write custom 2D physics simulations and interactive game mechanics in Python and Pygame — calculating vector dot products, handling impulse collisions, and managing tight gameloops in pure code without game engine shortcuts.

Building software at that fundamental layer taught me something invaluable: software is fragile when you don't understand how state, memory, and inputs interact.

"You cannot comprehensively fortify a system you don't know how to build from the ground up. The best security practitioners understand the perspective of the developer who wrote the bug."

Today, as a dedicated Cyber Security Student, I channel that exact curiosity into offensive and defensive cybersecurity. I audit network protocols, experiment with raw socket sniffers, learn how misconfigurations happen, and write practical security tooling to make systems more resilient.
